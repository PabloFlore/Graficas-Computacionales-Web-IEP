# Graficas-Computacionales-Web-IEP
Proyecto de videojuego web para la materia de Gráficas Computacionales Web

I. Visión General del Proyecto

Concepto: Juego de acción, sigilo y supervivencia en 3D con estética de Mini-Metrópolis nocturna.

Stack Tecnológico: Three.js (WebGL), HTML5, CSS3, JavaScript, PHP y MySQL para persistencia de datos.

3. Detalle de Pantallas a Desarrollar (UI/CSS)
• Menú Inicial: Título del juego, botones de navegación y arte de fondo.
• Configuraciones: Ajustes de volumen, sonido y selección de dificultad.
• Puntuaciones: Tabla HTML diseñada para consumir la API de MySQL.
• Pantalla de Juego (HUD): Contenedor Canvas 30, barras de estado y mini-mapa.
• Menú de Pausa: Ventana emergente con opciones de reanudar y salir.

Roles y Responsabilidades
• Diseñador de Interfaz y Ambientación: Creación del archivo estilos .css, maquetación de pantallas
e integración visual.
• Programador de Lógica: Transición JS entre vistas y guardado de preferencias locales
(LocalStorage).
• Programador Integrador 3D I Servicios: Estructura del Canvas para WebGL y diseño de la tabla de
puntuaciones
